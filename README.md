# Kedi Miyav Çeviri Makinesi

## Dünyanın En Ciddi, En Bilimsel ve En Abartılı Dilbilim Projesi

Bu repository, insan dilini kedi miyavlarına çeviren devrim niteliğinde bir teknolojidir. Yıllar süren (asılında 5 dakikalık) araştırmalar sonucunda ortaya çıkan bu eser, kedilerin gizli dilini çözmeyi amaçlar. Her kelime, rastgele ama bilimsel olarak miyavlara dönüştürülür. Hiçbir anlam kaybolmaz, sadece miyavlaşır.

### Nasıl Çalışır?

```bash
python kedi_miyav.py "Merhaba dünya, ben bir insanım"
```

Çıktı olarak size en saf, en katıksız miyavları sunar. Bu, modern bilimin zirvesidir.

### Özellikler

- Tamamen Türkçe uyumlu (ama miyav çıkar)
- Rastgele miyav seçimi (bilimsel rastgelelik)
- Sonsuz olasılıklar (asılında sınırlı)
- Abartılı ciddiyet

### Uyarı

Bu programı çalıştırmak kedilerin sizi anlamasına neden olabilir. Sorumluluk kabul etmiyoruz.
